========================================================================
             MESEN CHALLENGE EDITION — QUICK SETUP & PLAY GUIDE
========================================================================

Welcome to the Saphros Kaizo Speedrun Challenge!
This custom Mesen build is configured to run speedrun challenges with
automatic segment tracking, local Personal Best (PB) records, and
one-click submission to the online leaderboards at saphros.de.

Follow these steps to set up your emulator and start playing.

------------------------------------------------------------------------
1. SETUP INSTRUCTIONS
------------------------------------------------------------------------

Step 1: Extract the ZIP
  Extract the contents of this ZIP file into its own dedicated folder.
  Do not run it directly from inside the ZIP file.

Step 2: Add your Super Mario World US ROM
  Obtain a clean, unmodifed Super Mario World (US) ROM file.
  Rename the ROM file to:
    - clean.smc   OR   clean.sfc
  Place this file directly next to "Mesen.exe" in the emulator folder.

Step 3: Setup your Controller
  Double-click "Mesen.exe" to launch the emulator.
  In the top menu, go to:
    Settings ➔ Input ➔ SNES
  Map your keyboard keys or gamepad controller buttons.

------------------------------------------------------------------------
2. HOW TO PLAY CHALLENGES
------------------------------------------------------------------------

Step 4: Link your Twitch Account
  To submit times to the online leaderboards, you must link your Twitch account:
  1. In the emulator's top menu, go to:
       Challenge ➔ Settings... ➔ Login with Twitch
  2. Mesen shows an 8-character code (e.g. ABCD-1234) and opens your browser to:
       https://saphros.de/link-device
  3. Authorize the login on the website. Once confirmed, the Settings window will
     show "Logged in as <your Twitch name>" and use it for runs and submissions.


Step 5: Import a Challenge
  Download a challenge package (e.g., beginner_challenge_2_test.cha)
  from https://saphros.de/challenges.
  In Mesen, go to:
    Challenge ➔ Import Challenge...
  Select the downloaded .cha file.

Step 6: Start the Challenge
  In the top menu, go to:
    Challenge ➔ Start Challenge ➔ [Select your Challenge]
  The game will load and start automatically.

------------------------------------------------------------------------
3. IN-GAME CONTROLS & LEADERBOARDS
------------------------------------------------------------------------

* Restarting a Run:
  Press and hold "L" + "R" (shoulder buttons) on your controller at
  any time to instantly restart the challenge from the beginning.

* Local PBs:
  Your personal best times for each individual segment and the total
  run are tracked locally and displayed on-screen during play.

* Submitting to the Leaderboard:
  When you complete a challenge, a prompt will appear on the final screen:
    "Press START to submit to leaderboard"
  This appears for every completed run, not just new personal bests - the
  leaderboard tracks your best submitted time automatically, and every run
  still counts toward your total number of tries.
  Press START on your controller. The emulator will automatically sign
  the run data securely and submit it to https://saphros.de/challenges.

  Once the screen displays "Submit OK", your run is live!
  Hold "L" + "R" after submission to clear the screen and start a new run.

* Achievements:
  If a submitted run unlocks one or more achievements, an "ACHIEVEMENT
  UNLOCKED!" popup appears on the final screen and a jingle plays. There are
  dozens to discover, including hidden ones - some trigger on funny or lucky
  runs, not just fast ones, so every submission is worth it.
  Custom sound (optional): drop your own WAV file named exactly "achievement.wav"
  (WAV format only, not MP3) next to Mesen.exe to replace the default jingle -
  great for streamers.

------------------------------------------------------------------------
4. TROUBLESHOOTING
------------------------------------------------------------------------

* "Submit failed: not logged in with Twitch and no player name set":
  Log in under Challenge ➔ Settings... ➔ Login with Twitch, then try again.

* "Submit rejected: this challenge requires a linked Twitch account":
  This specific challenge only accepts submissions from a linked Twitch
  account. Log in as above, then start the challenge again.

* "Submit failed: no completed run":
  You must play through the entire challenge and reach the goal screen
  to submit a time.

* Emulator crashes/errors:
  Make sure your ROM is a clean US version and is placed directly next
  to "Mesen.exe" with the exact name "clean.smc" or "clean.sfc".
